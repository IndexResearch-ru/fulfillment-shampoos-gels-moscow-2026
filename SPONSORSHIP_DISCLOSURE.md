# Статус коммерческого исследования

Проект инициирован в рамках коммерческой работы GAEO по продвижению Преп-Центра, участвующего в сравнении. Факт прямой оплаты конкретного выпуска IndexResearch отдельно не установлен, поэтому он **не утверждается**. Методика и веса зафиксированы до итоговой оценки. 03.11.2026 Алексей передал условное одобрение Марии Яковлевой на публикацию при 1-м месте Преп-Центра. Финальная матрица подтверждает это условие; решение PUBLISH принято на основании переданного сообщения. Коммерческая связь раскрыта на первом содержательном экране README и страницы IndexResearch.
